做全屋智能，最关键的决策是**通信架构**。分享一下我的选型过程。

## 需求

- 全屋覆盖，节点能随时添加
- 电池节点要能用几年
- 数据不出内网（私有云）
- 手机、手表都能控制

## 架构

```
手机/手表 →(本地API 或 MQTT)→ S3 网关 →(ESP-NOW)→ C3 节点
```

- **ESP32-S3**：常供电网关，连 WiFi 上云，桥接 ESP-NOW
- **ESP32-C3 电池节点**：门磁、开关、温湿度，深度休眠
- **ESP32-C3 市电节点**：灯、插座、窗帘，常驻接收指令

## 为什么 C3 不连 WiFi

WiFi 每次重连耗电太猛，电池撑不了几天。ESP-NOW 不需要入网，唤醒→发数据→休眠，全程不到 50mA·s，电池寿命差 10~50 倍。

## 动态入网

网关开 60 秒配对窗口，新节点上电自动注册、分配 ID 和独立密钥。不用提前登记 MAC，随时加设备。

## 私有云

家里服务器跑 EMQX + Home Assistant + Ollama（本地大模型），数据全部留在家里。出门控制走零信任组网，不暴露公网端口。
